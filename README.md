# JEWEL SURVIVOR

iPhone の Safari でそのまま動く、宝石テーマのヴァンパイアサバイバーライク。
黒基調の画面で、宝石と光のパーティクルが映えるように作っています。

- **操作**：画面のどこでもドラッグで仮想スティック。攻撃はすべて自動
- **15ステージ（第1章 5・第2章 6・第3章 4）**：それぞれ固有のギミックと最終ボス

- **ヒート**：クリアしたステージは難易度を最大10段階まで上げて再挑戦（コイン倍率アップ）。エンドレス・HYPER（高速）・HURRY（時間2倍速）も選べる
- **BOSS モード**：クリアしたステージのボスたちと連戦。武器・チャームを自由に選んで Lv1 から、強化はボスの宝箱だけ。1 周ごとにボスが 2 倍に
- **16種の宝石武器＋14種のチャーム**
- **装備枠**：武器4・チャーム6。レベルアップではリロール・スキップ・バニッシュ（候補から除外）が使える
- **進化**：武器Lv8＋対応チャームで進化
- **1戦7分**（虚空聖堂は8分）。2:00・4:00に中ボス、最後に最終ボス
- **秘宝**：ランの性質を変える宝石の道具11種（ヴァンサバのアルカナ相当）。開始時に1つ持ち込み、2体目以降の中ボスからもう1つ
- **属性**：全宝石に8属性（炎・水・氷・草・雷・光・闇・土）。命中時にたまに状態異常、同じ属性を揃えると効果アップ
- **敵**：遠距離・分裂・突進・自爆・冷気・瞬間移動などの新種と、ステージごとの中ボス
- **報酬演出**：レア度付き強化カード、LUCKY×2、宝箱スロット、フィーバー、コンボ、JACKPOT、奇跡、実績、ログインボーナス
- **メタ要素**：工房・上位工房（永続強化・返金）、研磨工房（原石を研磨して宝石をコレクション。練度で永続ボーナス、実在の宝石の豆知識つき）、採掘（原石ガチャ）＋交換所（覚醒など）、ユーザーランク（獲得コインアップ）、図鑑（武器・チャーム・敵・秘宝・ステージ）、実績、遊び方、ジュークボックス（BGM 鑑賞）、セーブのファイルバックアップ
- グラフィックとサウンドはすべてコードで生成（画像・音声ファイルなし）
- PWA 対応：ホーム画面に追加すると全画面＋オフラインで動作

## プレイ方法（iPhone）

1. 公開 URL を Safari で開く
2. 共有メニュー →「ホーム画面に追加」で全画面アプリとして起動（推奨）
3. START → ジュエルを選んで DEPLOY

PC では WASD／矢印キーで移動、P／Esc でポーズ。

## ローカル実行

ES Modules を使っているので、簡易サーバー経由で開いてください。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

## 公開（GitHub Pages）

`.github/workflows/pages.yml` を同梱しています。**Settings → Pages → Source を「GitHub Actions」** にすると、`main` への push ごとに自動デプロイされます。

## デバッグ用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?auto=ruby` | タイトルを飛ばして即開始（ジュエルID） |
| `&bot` | 自動プレイ（バランス確認用） |
| `&speed=8` | 早送り |
| `&norender` | 描画なし（高速シミュレーション） |
| `&t=300` | 開始時刻（秒） |
| `&god` | 無敵 |
| `&build=ruby,amber:evo` | 指定武器をLv8（`all` で装備枠いっぱい）、`:evo` で進化済み |
| `&stage=cavern` | ステージ指定（wastes / cavern / magma / tundra / void / deep / rlyeh / lake / carcosa / space / azathoth / yushu / uzan / sanki / chuou） |
| `&hyper` / `&hurry` / `&endless` | 各モードで開始 |
| `&art=grail` | 秘宝を持って開始 |
| `&heat=3` | ヒート指定 |
