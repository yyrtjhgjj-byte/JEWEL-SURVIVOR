# 💎 JEWEL SURVIVOR（ジュエル・サバイバー）

**iPhone の Safari で そのまま あそべる**、キラキラ ドパドパ なヴァンパイアサバイバー風ゲーム。
ジュエルの ちから（宝石ことば）で、せかいの かがやきを うばう「くすみ団」を ぶっとばせ！

- 🎮 **どこでも タッチで スティック**：がめんを なぞるだけで うごく。こうげきは ぜんぶ自動。
- 💎 **12しゅるいの ジュエルぶき ＋ 12しゅるいの チャーム**：宝石ことばは『ジュエルペット』の ジュエルパワーが もと（→ [docs/GEMS.md](docs/GEMS.md)）
- 🌈 **しんか**：ぶき Lv8 ＋ たいおうする チャームで しんか！
- 🎉 **ドパミン まみれ**：レベルアップ連発、レア度つきカード、ラッキー×2、たからばこスロット、フィーバー、コンボ、JACKPOT 777、キセキ10倍ダメージ、100たい/1000たい げきは ボーナス、トロフィー、ログインボーナス、ガチャ
- 👑 **10ぷんで ラスボス**：3ぷん くすみキング → 6ぷん ヤミドラゴン → 10ぷん ダーク・クイーン。クリアで エンドレスモード かいほう
- 🛠 **ジュエル工房**（えいきゅう強化）・**キラキラガチャ**（キャラかいほう／かくせい）・**ずかん**
- 🔊 音も 絵も ぜんぶ コードで その場で 生成（画像・音声ファイルなし）
- 📱 ホーム画面に追加で ぜんがめん＋オフライン対応（PWA）

## あそびかた（iPhone）

1. GitHub Pages などで公開した URL を Safari で ひらく
2. （おすすめ）共有ボタン →「ホーム画面に追加」で ぜんがめんアプリに
3. 「あそぶ！」→ ジュエルを えらんで スタート

PC では WASD / やじるしキーで うごけます（P / Esc でポーズ）。

## ローカルで うごかす

ES Modules を つかっているので、ファイルを ちょくせつ ひらくのではなく かんたんな サーバーで ひらいてください。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

## 公開（GitHub Pages）

`.github/workflows/pages.yml` が入っています。リポジトリの **Settings → Pages → Source を「GitHub Actions」** にすると、`main` に push するたびに自動で公開されます。

## テスト用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?auto=ruby` | タイトルを とばして すぐ スタート（ジュエルID） |
| `&bot` | 自動プレイ（バランス確認用） |
| `&speed=8` | 早送り |
| `&norender` | 描画なし（高速シミュレーション用） |
| `&t=300` | 開始時間（秒） |
| `&god` | むてき |
| `&build=all:evo` | ぶき全部 Lv8＋しんか状態で開始 |
