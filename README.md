# JEWEL SURVIVOR

iPhone の Safari でそのまま動く、宝石テーマのヴァンパイアサバイバーライク。
黒基調の画面で、宝石と光のパーティクルが映えるように作っています。

- **操作**：画面のどこでもドラッグで仮想スティック。攻撃はすべて自動
- **5ステージ**：それぞれ固有のギミックと最終ボス
  | # | ステージ | ギミック | 最終ボス |
  |---|---|---|---|
  | 1 | 黒曜の荒野 | なし | オブシディアン・クイーン |
  | 2 | 水晶洞窟 | 水晶柱（通行不可・敵弾を遮る） | プリズム・コロッサス（回転レーザー） |
  | 3 | 灼熱鉱脈 | 溶岩だまり・噴火 | マグマ・ワーム（胴体つきの大蛇） |
  | 4 | 凍晶氷原 | 吹雪（減速・視界不良・風） | フロスト・リッチ（氷柱・冷気） |
  | 5 | 虚空聖堂（12分） | 暗闇・虚空の裂け目 | ヴォイド・エンペラー（3形態） |
- **ヒート**：クリアしたステージは難易度を最大5段階まで上げて再挑戦（コイン倍率アップ）。エンドレスも可
- **15種の宝石武器＋13種のチャーム**：能力テーマは『ジュエルペット』のジュエルパワー準拠 → [docs/GEMS.md](docs/GEMS.md)
- **進化**：武器Lv8＋対応チャームで進化
- **敵**：遠距離・分裂・突進・自爆・冷気・瞬間移動などの新種と、ステージごとの中ボス
- **報酬演出**：レア度付き強化カード、LUCKY×2、宝箱スロット、フィーバー、コンボ、JACKPOT、奇跡、実績、ログインボーナス、ガチャ
- **メタ要素**：工房（永続強化）、ガチャ（ジュエル解放／覚醒）、図鑑（武器・チャーム・敵・ステージ）、実績
- グラフィックとサウンドはすべてコードで生成（画像・音声ファイルなし）
- PWA 対応：ホーム画面に追加すると全画面＋オフラインで動作

## プレイ方法（iPhone）

1. 公開 URL を Safari で開く
2. 共有メニュー →「ホーム画面に追加」で全画面アプリとして起動（推奨）
3. START → ジュエルを選んで DEPLOY

PC では WASD／矢印キーで移動、P／Esc でポーズ。

## ローカル実行

ES Modules を使っているので、簡易サーバー経由で開いてください。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

## 公開（GitHub Pages）

`.github/workflows/pages.yml` を同梱しています。**Settings → Pages → Source を「GitHub Actions」** にすると、`main` への push ごとに自動デプロイされます。

## デバッグ用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?auto=ruby` | タイトルを飛ばして即開始（ジュエルID） |
| `&bot` | 自動プレイ（バランス確認用） |
| `&speed=8` | 早送り |
| `&norender` | 描画なし（高速シミュレーション） |
| `&t=300` | 開始時刻（秒） |
| `&god` | 無敵 |
| `&build=all:evo` | 武器6種Lv8＋進化済みで開始 |
| `&stage=cavern` | ステージ指定（wastes / cavern / magma / tundra / void） |
| `&heat=3` | ヒート指定 |

## ファイル構成

```
index.html            画面の骨組み
css/style.css         UI（ダーク／プリズムテーマ）
js/main.js            起動・メインループ・セーブ連携・タイトル背景
js/game.js            ゲーム本体（出現・当たり判定・ボス・フィーバー）
js/weapons.js         15武器の挙動と進化
js/stages.js          ステージ定義（出現表・イベント・ヒート）
js/enemies.js         新種の敵とボスの行動
js/hazards.js         ステージギミック（柱・溶岩・吹雪・暗闇）
js/data.js            ジュエル・ジュエルパワー・武器・敵・工房・実績
js/render.js          宝石／敵／キャラの手続き型描画
js/fx.js              パーティクル・ダメージ表示・雷
js/audio.js           WebAudio 効果音＋BGMシーケンサー
js/ui.js              各画面（タイトル・レベルアップ・宝箱・ガチャ・図鑑・リザルト）
js/input.js           フローティング仮想スティック
sw.js                 オフラインキャッシュ
docs/GEMS.md          ジュエルパワーまとめ
tools/icon.html       アイコン生成
```
