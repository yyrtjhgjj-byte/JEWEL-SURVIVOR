# JEWEL SURVIVOR

iPhone の Safari でそのまま動く、宝石テーマのヴァンパイアサバイバーライク。
黒基調の画面で、宝石と光のパーティクルが映えるように作っています。

- **操作**：画面のどこでもドラッグで仮想スティック。攻撃はすべて自動
- **12種の宝石武器＋12種のチャーム**：能力テーマは『ジュエルペット』のジュエルパワー（宝石言葉）準拠 → [docs/GEMS.md](docs/GEMS.md)
- **進化**：武器Lv8＋対応チャームで進化
- **報酬演出てんこ盛り**：レア度付き強化カード、LUCKY×2、宝箱スロット、フィーバー、コンボ、JACKPOT 777、10倍ダメージの「奇跡」、撃破数ボーナス、実績、ログインボーナス、ガチャ
- **ステージ**：3:00 ダスク・キング → 6:00 ヴォイド・ドラゴン → 10:00 オブシディアン・クイーン。クリアでエンドレスモード解放
- **メタ要素**：工房（永続強化）、ガチャ（ジュエル解放／覚醒）、図鑑、実績
- グラフィックとサウンドはすべてコードで生成（画像・音声ファイルなし）
- PWA 対応：ホーム画面に追加すると全画面＋オフラインで動作

## プレイ方法（iPhone）

1. 公開 URL を Safari で開く
2. 共有メニュー →「ホーム画面に追加」で全画面アプリとして起動（推奨）
3. START → ジュエルを選んで DEPLOY

PC では WASD／矢印キーで移動、P／Esc でポーズ。

## ローカル実行

ES Modules を使っているので、簡易サーバー経由で開いてください。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

## 公開（GitHub Pages）

`.github/workflows/pages.yml` を同梱しています。**Settings → Pages → Source を「GitHub Actions」** にすると、`main` への push ごとに自動デプロイされます。

## デバッグ用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?auto=ruby` | タイトルを飛ばして即開始（ジュエルID） |
| `&bot` | 自動プレイ（バランス確認用） |
| `&speed=8` | 早送り |
| `&norender` | 描画なし（高速シミュレーション） |
| `&t=300` | 開始時刻（秒） |
| `&god` | 無敵 |
| `&build=all:evo` | 武器6種Lv8＋進化済みで開始 |

## ファイル構成

```
index.html            画面の骨組み
css/style.css         UI（ダーク／プリズムテーマ）
js/main.js            起動・メインループ・セーブ連携・タイトル背景
js/game.js            ゲーム本体（出現・当たり判定・ボス・フィーバー）
js/weapons.js         12武器の挙動と進化
js/data.js            ジュエル・宝石言葉・武器・敵・工房・実績
js/render.js          宝石／敵／キャラの手続き型描画
js/fx.js              パーティクル・ダメージ表示・雷
js/audio.js           WebAudio 効果音＋BGMシーケンサー
js/ui.js              各画面（タイトル・レベルアップ・宝箱・ガチャ・図鑑・リザルト）
js/input.js           フローティング仮想スティック
sw.js                 オフラインキャッシュ
docs/GEMS.md          宝石言葉まとめ
tools/icon.html       アイコン生成
```
